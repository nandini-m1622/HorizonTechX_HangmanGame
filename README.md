# 🎮 Hangman Game in Python

A simple text-based **Hangman Game** built using Python. The player tries to guess a randomly selected word one letter at a time before running out of attempts.

## 📌 Features

- Randomly selects a word from a predefined list
- Allows the player to guess one letter at a time
- Maximum of **6 incorrect guesses**
- Prevents duplicate guesses
- Displays the current progress of the word
- Simple console-based interface
- Beginner-friendly Python project

## 🛠️ Technologies Used

- Python 3
- Random Module


3. Run the program:

```bash

```

## 🎯 How to Play

1. The game randomly chooses a word.
2. The player enters one letter at a time.
3. If the letter is correct, it appears in the word.
4. If the letter is incorrect, one attempt is lost.
5. The player wins by guessing the entire word before using all **6 attempts**.
